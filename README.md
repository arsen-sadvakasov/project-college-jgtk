# Жетісу гуманитарлық-техникалық колледжі — Веб-сайт

Ресми веб-сайт Жетісу гуманитарлық-техникалық колледжі (Есік қаласы). Сайт заманауи дизайнмен, интерактивті элементтермен және толыққанды ақпараттық блоктармен жабдықталған.

## 🚀 Ерекшеліктері

- **Көпбетті құрылым**: Басты бет, Мамандықтар, Колледж туралы, Талапкерге және Байланыс.
- **Премиум Дизайн**: Bento-grid орналасуы, заманауи типографика және таза интерфейс.
- **Интерактивтілік**: 
  - GSAP және ScrollTrigger көмегімен анимациялар.
  - Lenis арқылы тегіс айналдыру (Smooth Scroll).
  - Грантқа түсу мүмкіндігін есептейтін калькулятор.
- **Көптілділік**: Қазақ және орыс тілдерін толық қолдау.
- **Бейімділік**: Барлық құрылғыларға (смартфон, планшет, десктоп) арналған респонсивті дизайн.
- **Қараңғы тақырып**: Көзді шаршатпайтын Dark Mode режимі.

## 📂 Жоба құрылымы

```text
├── index.html              # Басты бет
├── about.html              # Колледж туралы
├── specialties.html        # Мамандықтар
├── admissions.html         # Талапкерге арналған ақпарат
├── contact.html            # Байланыс беті
├── 404.html                # Қате беті
├── policy.html             # Құпиялылық саясаты
└── assets/
    ├── css/                # СТИЛЬДЕР (style.css)
    ├── js/                 # СКРИПТТЕР (script.js)
    │   └── vendor/         # СЫРТҚЫ КІТАПХАНАЛАР (GSAP, Lenis)
    └── img/                # ФОТО ЖӘНЕ ЛОГОТИПТЕР
```

## 🛠 Технологиялар

- **HTML5** & **Vanilla CSS3**
- **JavaScript (ES6+)**
- **GSAP** (GreenSock Animation Platform)
- **Lenis** (Smooth Scrolling)
